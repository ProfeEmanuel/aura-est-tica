
# Aura Estética

Site demonstrativo de uma clínica fictícia de estética,
desenvolvido para o portfólio da WDIT Services.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Layout responsivo
- Apresentação de tratamentos
- Navegação por seções
- Links de contato pelo WhatsApp
- Identidade visual em bege, branco e dourado

## Executar localmente

Abra o arquivo index.html no navegador.

## Observação

Projeto fictício para demonstração.
Informações, serviços e contato devem ser
adaptados e verificados antes de qualquer
utilização comercial.
